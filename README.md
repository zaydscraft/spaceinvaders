# 🚀 Space Invaders – Zayd Edition 👾

A vibrant, modern take on the classic Space Invaders arcade game — built with love for Zayd!

## 🎮 Play Now

Just open `index.html` in any modern browser — no installation needed!

Or host it on GitHub Pages for instant online play.

---

## ✨ Features

- 🎨 **Vibrant neon visuals** — animated starfield, glowing aliens, particle explosions
- 🔊 **Synthesized sound effects** — all sounds generated with Web Audio API (no files needed!)
- 📱 **Fully responsive** — works on desktop, tablet, and smartphone
- ⌨️ **Keyboard controls** — Arrow keys / WASD to move, SPACE to shoot
- 👆 **Touch controls** — on-screen buttons for mobile play
- 🏆 **High score** — saved locally between sessions
- 👾 **5 levels** of increasing difficulty
- 🛸 **UFO bonus** — random UFO flies across for bonus points
- 🛡️ **4 shields** to hide behind
- 💥 **Particle explosions** with screen flash effects
- ⭐ **Level complete** celebrations

## 🚀 Deploying to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Visit `https://your-username.github.io/space-invaders-zayd/`

---

## 🛠️ Tech Stack

- Pure **HTML5 / CSS3 / Vanilla JavaScript**
- **Canvas API** for game rendering
- **Web Audio API** for synthesized sound effects
- **CSS animations** for UI effects
- Google Fonts: **Press Start 2P** + **Orbitron**
- Zero external dependencies!
